游戏性能优化中心 v5.0 · 便携版
========================================

一、快速开始
  1. 先把整个压缩包解压到一个固定文件夹（不要直接在压缩包里双击）。
  2. 双击“启动优化脚本.bat”。
  3. Windows 弹出管理员权限请求时，点“是”。
  4. 打开界面后，先在“概览”查看硬件，再到“优化项”按需勾选，点“应用选中项”。
  5. 概览页的 CPU / GPU / RAM / 显示存储 卡片支持悬停高亮，点击可查看只读详情，并可直接复制或跳转诊断报告。

  启动行为：启动器以隐藏方式运行，不会再停留黑色控制台窗口；
  如果加载期间你切到了别的程序，主窗口不会抢焦点，只会闪烁任务栏图标提示。

二、QQ / Windows 拦截说明
  · 请用“以文件发送”的方式发送 zip；对方收到后先解压再运行。
  · 若出现“Windows 已保护你的电脑”：点“更多信息” → “仍要运行”。
  · 若提示脚本被系统禁止：右键 zip → 属性 → 勾选“解除锁定” → 确定，再重新解压。
  · 启动器会自动执行 Unblock-File，解除从网络下载的脚本锁定。
  · 杀毒软件可能对修改注册表 / 电源计划的脚本报警。本工具除“检查更新”外不联网、不下载、
    不修改系统文件，所有改动都有原值备份。

三、它做什么
  · 只读检测 + 可逆的注册表 / 电源 / 显示 / 网卡设置优化。
  · 应用前自动备份原值（backups 文件夹），支持单项还原、最近一次撤销、全部回放。
  · 不修改 Defender、不关闭系统服务、不改 BCD、不超频、不改 DNS/hosts。
  · 驱动中心：Intel 设备以本机“Intel 驱动支持助手（DSA）”的记录为准；NVIDIA 设备检测到
    NVIDIA App（或 GeForce Experience）时显示官方工具卡片，AMD 设备检测到 AMD Software 时同理。
    未检测到对应硬件或官方工具就不显示该卡片；未装 DSA 的 Intel 设备回退到 Windows Update。
    若检测到“已装过新版本但系统被回退”，会标红提示，详情里可查看版本信息并打开官方工具。
  · 驱动变化记录：每次扫描都会与上次结果比对，升级、回退或重新绑定写入 data\driver-history.json；
    驱动中心顶部的“变化记录”可查看最近 20 条。详情页的“重新绑定驱动”会用当前 INF 重新安装一次，
    用于设备状态异常或刚被系统回退的情况。
  · 游戏库：自动识别 Steam / Epic 已安装游戏，也可手动添加 exe。选中游戏后可设置进程优先级、
    核心亲和性、关闭全屏优化、优先高性能显卡与启动参数；写入的注册表项都能用“恢复原值”写回。
    优先级与核心亲和性只在“启动游戏”时对本次进程生效，不常驻。
  · 启动项：只读展示注册表 Run/RunOnce、启动文件夹与内存占用较高的后台进程，不提供一键禁用；
    需要调整时请使用 Windows 设置 → 应用 → 启动，或任务管理器。
  · 诊断包：诊断报告页“导出诊断包”会在本地生成 zip（系统信息、dxdiag、驱动与设备列表、
    最近 24 小时错误事件、优化状态、本机配置与最近日志），不上传，可发给他人协助排查。
  · 托盘：设置里可开启“关闭窗口时最小化到托盘”；驱动版本变化且开启通知时，会通过托盘气泡提醒。
  · 检查更新：关于页“检查更新”会读取 GitHub Releases 的最新版本，只在点击时联网。

四、数据与隐私
  · 设置、备份、日志都保存在解压后的文件夹内，不联网、不上传。
  · “检查更新”是唯一会主动联网的功能，且只在点击后请求 GitHub Releases。
  · 分享包不包含原作者的本机设置、备份和日志。

五、系统要求
  · Windows 10 / 11（64 位）
  · Windows PowerShell 5.1（系统自带）
  · 建议 1920×1080 及以上；高缩放屏幕可在“设置”里开启实验性高 DPI。
  · “设置 → 外观与通知”可切换深色 / 浅色主题（重启界面生效），并配置托盘与驱动通知。

六、卸载
  · 直接删除整个文件夹即可；如已应用优化项，请先在“备份还原”里还原。

七、关于启动时的“检测中”
  · 为了让界面更快出现，窗口会先显示出来，此时优化项状态显示为“检测中”；
    约 1 秒后自动补全真实状态，不需要手动刷新或重启。

八、支持作者

    界面里的“关于”页底部也有“支持作者”按钮。
