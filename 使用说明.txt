游戏性能优化中心 v6.3.0 · WinUI 3 便携版
========================================

一、快速开始
  1. 先把整个压缩包解压到一个固定文件夹（不要直接在压缩包里双击）。
  2. 双击“GamePerfCenter.exe”。
  3. Windows 弹出管理员权限请求时，点“是”。
  4. 打开界面后，先在“概览”查看硬件，再到“优化项”按需勾选，点“应用选中项”。

  备用入口：如果原生界面无法启动，进入“备用-WinForms”目录，双击“启动优化脚本.bat”，
  使用旧版界面；功能与数据完全一致。

  启动行为：程序不会停留黑色控制台窗口；如果加载期间你切到了别的程序，
  主窗口不会抢焦点，只会闪烁任务栏图标提示。

二、QQ / Windows 拦截说明
  · 请用“以文件发送”的方式发送 zip；对方收到后先解压再运行。
  · 若出现“Windows 已保护你的电脑”：点“更多信息” → “仍要运行”。
  · 若提示脚本被系统禁止：右键 zip → 属性 → 勾选“解除锁定” → 确定，再重新解压。
  · 启动器会自动执行 Unblock-File，解除从网络下载的脚本锁定。
  · 杀毒软件可能对修改注册表 / 电源计划的脚本报警。本工具除“检查更新”外不联网、不下载、
    不修改系统文件，所有改动都有原值备份。

二之二、优化引擎报错时怎么办
  · 如果引擎启动失败或中途退出，界面会弹出“优化引擎出错了”，先说明退出代码与最可能的原因，
    再列出可以逐条执行的排查步骤；点“技术详情”可展开环境检测、错误位置、调用栈与日志末尾。
  · 点“重新连接”会重启引擎并重新读取硬件；仍然失败时会就地刷新这份报告。
  · 点“复制报告”可把完整内容复制到剪贴板，点“打开日志目录”可查看
    data\engine-report_时间.txt 与 data\engine.log。
  · 报告只在本机生成，不会上传。遇到无法自行解决的问题时，把报告发给作者即可定位。
  · 常见原因：PowerShell 执行策略 / 语言模式被策略限制、WMI 组件损坏、程序放在不可写目录、
    安全软件拦截 powershell.exe。报告会标明检测结果，并按结果给出对应命令。

三、它做什么
  · 只读检测 + 可逆的注册表 / 电源 / 显示 / 网卡设置优化。
  · 应用前自动备份原值（backups 文件夹），支持单项还原、最近一次撤销、全部回放。
  · 不修改 Defender、不关闭系统服务、不改 BCD、不超频、不改 DNS/hosts。
  · 驱动中心：Intel 设备以本机“Intel 驱动支持助手（DSA）”的记录为准；NVIDIA 设备检测到
    NVIDIA App（或 GeForce Experience）时显示官方工具卡片，AMD 设备检测到 AMD Software 时同理。
    未检测到对应硬件或官方工具就不显示该卡片；未装 DSA 的 Intel 设备回退到 Windows Update。
    若检测到“已装过新版本但系统被回退”，会标红提示，详情里可查看版本信息并打开官方工具。
  · 驱动变化记录：每次扫描都会与上次结果比对，升级、回退或重新绑定写入 data\driver-history.json；
    驱动中心底部的“最近驱动变更”可查看最近记录。
  · 驱动管理：在驱动中心点设备右侧“管理”，可以重新绑定当前驱动、切换到仓库中的其它驱动包，
    或清理不再使用的旧驱动包。写操作前会二次确认，并自动捕获、恢复音频端点静音状态；
    当前正在使用的驱动包不允许清理，涉及重启的项目会明确提示。
  · 游戏库：自动识别 Steam / Epic / WeGame 已安装游戏，也可手动添加任意 exe。
    点列表行右侧的“编辑”（或双击整行）打开启动方案：进程优先级、核心亲和性、关闭全屏优化、
    优先高性能显卡、以管理员身份启动与启动参数；可“保存方案”或“保存并应用”。
    手动添加的条目可在编辑弹窗里“从游戏库移除”（只删库记录，不删游戏文件）。
    优先级与核心亲和性只在“启动游戏”时对本次进程生效，不常驻。
  · 启动项：只读展示注册表 Run/RunOnce、启动文件夹与内存占用较高的后台进程，不提供一键禁用；
    需要调整时请使用 Windows 设置 → 应用 → 启动，或任务管理器。
  · 诊断包：诊断报告页“导出诊断包”会在本地生成 zip（系统信息、dxdiag、驱动与设备列表、
    最近 24 小时错误事件、优化状态、本机配置与最近日志），不上传，可发给他人协助排查。
  · 托盘：设置里可开启“关闭窗口时最小化到托盘”；驱动版本变化且开启通知时，会通过托盘气泡提醒。
  · 检查更新：关于页“检查更新”会读取 GitHub Releases 的最新版本，只在点击时联网。

三之二、命令行 gpc（可选）
  · 发布包内另附单文件 CLI，解压后直接运行 gpc.exe，不需要安装 .NET。
  · gpc items list --status          列出优化项并检测状态
  · gpc items apply --dry-run        预览推荐项，不写入系统
  · gpc items apply --yes            实际应用并生成备份
  · gpc items restore --latest --dry-run  校验最近一份备份
  · gpc drivers scan                 查看设备与驱动仓库
  · gpc audio restore                恢复本次捕获到的音频静音状态
  · 驱动写操作默认只预览，确认后加 --yes；命令帮助：gpc --help。

四、数据与隐私
  · 设置、备份、日志都保存在解压后的文件夹内，不联网、不上传。
  · “检查更新”是唯一会主动联网的功能，且只在点击后请求 GitHub Releases。
  · 分享包不包含原作者的本机设置、备份和日志。

五、系统要求
  · Windows 10 1809 / 11（64 位）
  · Windows PowerShell 5.1（系统自带，引擎依赖）
  · 便携版已自包含 .NET 与 Windows App SDK，无需单独安装运行时。
  · 建议 1920×1080 及以上；程序已按系统缩放自动适配，无需手动开启高 DPI 选项。
  · “设置 → 外观”可切换深色 / 浅色 / 跟随系统，立即生效；“行为”里可配置托盘与驱动通知。

六、卸载
  · 直接删除整个文件夹即可；如已应用优化项，请先在“备份还原”里还原。

七、关于启动时的“检测中”
  · 为了让界面更快出现，窗口会先显示出来，此时优化项状态显示为“检测中”；
    约 1 秒后自动补全真实状态，不需要手动刷新或重启。

八、支持作者
